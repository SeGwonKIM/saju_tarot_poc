## 3. 검토자 판단과 다른 곳 1건

### §4-2 [보완] — "서울/울릉도가 같은 시주면 보정이 안 걸린 신호"

> "서울/울릉도가 같은 시주라는 결과는 **보정량이 허용치보다 작거나 보정이 아예 적용되지
> 않았다**는 신호입니다."

**이건 사실이 아닙니다.** 확인한 값은 이렇습니다.

```
경도 보정 차이   실제 16분  /  이론 (130.9057-126.9780)×4 = 15.7분   → 규칙대로 작동
같은 시주가 되는 이유   시주는 2시간 단위인데 16분 차이라 대부분의 시각에서 경계를 안 넘음
실제로 갈리는 시각   01:24 — 서울 戊子 / 울릉도 己丑
```

보정은 **정확히 걸리고 있었습니다.** 다만 제 검사가 `확인(..., True, ...)` 여서 그걸
증명하지 못했을 뿐입니다. 지금은 두 가지로 바꿨습니다 — **(a) 4분 규칙 검산**,
**(b) 실제로 갈리는 시각을 24시간에서 탐색**. 둘 다 변이 시험에 등록했습니다.

검토자가 코드를 못 본 상태에서 출력만으로 추정한 것이므로 무리한 판단은 아닙니다.
다만 **결론은 반대**였습니다.

## 1번 — 빈 집합 방어 (신규)

유형 A 의 나머지 절반이었습니다. F-15(리터럴 상수)는 AST 로 자동 탐지하게 만들었지만,
**F-14(검사 대상 0개)는 여전히 자동으로 못 막고 있었습니다.**

확인해 보니 **방어 코드가 한 곳도 없었습니다.** 넣었습니다.

| | 무엇 |
|---|---|
| `verify/guard.py` | `표본확인()` — 표본이 없으면 **멈춘다**. `모두()` — `all()` 대신, **분모를 같이 돌려줌** |
| 검증 스크립트 6개 | 시작부에 `표본확인()` 추가 (s1_extract·s1_stt·s3_time·s4_repro·s4a_code·s6_cost) |
| `A1 정적 검사` | `verify/`·`poc/` 의 **모든 `all()` / `not any()` 를 AST 로 수집**. `guard.py` 의 검토 목록에 이유가 적혀 있지 않으면 **게이트가 실패** |

```
A1 · 빈 집합에서 참이 되는 전칭 양화가 전부 검토됐는가   발견 3곳 · 미등록 0곳
A1 · 모두()가 빈 집합을 통과로 치지 않는가              all([]) 는 True 이지만 모두([]) 는 False
A1 · 표본확인()이 빈 표본에서 멈추는가                  표본 0건이면 검사를 돌리지 않고 멈춘다
```

**새 `all()` 을 쓰면 이유를 적기 전까지 게이트가 통과하지 않습니다.**
