## 3. 이미 스스로 찾은 오류 — 같은 종류가 더 있는지 봐 주십시오

### ⚠ 유형 A — **성립하지 않는 시험을 통과로 셈**

가장 위험한 종류입니다. 두 건 나왔습니다.

| | 무엇 | 왜 위험한가 |
|---|---|---|
| **F-14** | 숨김 1차 3건에 `null` 이어야 할 자리가 **0개**였는데 "지어냄 0건 통과"라고 적음 | **검사가 한 번도 발동하지 못했는데** 통과로 셈 |
| **F-15** | S2 의 16번째 검사가 `확인("경도에 따라 시주가 갈릴 수 있음", **True**, ...)` | 조건이 리터럴 `True`. 절대 실패 불가. 출력은 `서울 甲午 / 울릉도 甲午` 로 **이름과 반대** |

둘 다 고쳤습니다(빈 자리 6개 심음 / 진짜 검사 2개로 교체 → 17/17).
**이 유형이 또 있는지가 1순위 점검 대상입니다.**

### ⚠ 유형 B — **문서가 없는 기능을 주장**

| | 무엇 |
|---|---|
| **F-12** | 문서 3곳이 **대운**을 산출한다고 적었으나 백엔드 전체에 구현 **0곳** |
| **F-13** | 그 파급으로 `gender` 를 추출·채점하는데 **쓰는 곳이 없음** (S1 5항목 중 1개가 허수) |

1. **칭찬은 필요 없습니다.** 틀린 곳만 짚어 주십시오.

3. 근거 없이 "괜찮아 보인다"고 하지 마시고, **파일과 줄 번호**로 짚어 주십시오.
4. 제가 **스스로 유리하게 기준을 옮긴 곳**이 있으면 그것이 가장 중요한 지적입니다.

## 6. 실행 방법 (검토자가 직접 돌려 보실 때)

```bash
pip install -r requirements.txt

python -m verify.s2_manseryeok                     # 만세력 17항목
python -m verify.s1_extract                        # 공개 5건, 기준선만
python -m verify.s1_extract --숨김2                 # 숨김 2차, 기준선만
python -m verify.s3_time                           # 시간 (가정값 포함)
python -m poc.pipeline --text samples/상담_001.txt --규칙 --초안없이
```

LLM 경로는 `OPENAI_API_KEY` 가 필요합니다. `--env=<경로>/.env` 로 줍니다.
**키는 저장소에 없습니다.**
