# S3 기준선 기록지 — 손으로 한 건 만들며 적는 종이

> **왜 필요한가**
> "수작업보다 5배 빠르다"고 말하려면 **수작업이 몇 분인지**를 알아야 합니다.
> 세탁기가 "손빨래보다 5배 빠릅니다"라고 하려면 손빨래 시간을 먼저 재야 하는 것과 같습니다.
>
> 지금 문서에 적힌 **65분은 재 본 적 없는 가정값**입니다.
> 이 종이를 채우면 그 자리에 실측이 들어갑니다.

---

## 어떻게 재나

**새로 할 일이 아닙니다.** 다음에 리포트 한 건 만드실 때, 각 토막을 시작할 때와
끝낼 때 시계를 한 번씩 보시면 됩니다. 초 단위로 정확할 필요 **전혀 없습니다.**

**중간에 다른 일을 하셨으면 그 시간은 빼 주세요.** (전화가 왔다든가)

## 다 채우신 뒤

`verify/s3_time.py` 파일 **위쪽**에 이 표가 있습니다. 숫자만 바꾸면 됩니다.

```python
수작업_분 = {
    "① 상담 받아 적기": 10,   # ← 여기
    "② 만세력 뽑기": 5,       # ← 여기
    "③ 해석 초안 쓰기": 40,   # ← 여기
    "④ 다듬어 보내기": 10,    # ← 여기
}
가정근거 = "일반 상담 1건 기준의 경험적 추정. 실측 아님."   # ← 이 줄도 고칩니다
```

바꾸고 나서 `python -m verify.s3_time` 을 돌리면 **가정이 아니라 실측 기준**의
비교가 나옵니다. 그때 S3 의 상태를 `미측정` 에서 `측정·달성/미달` 로 올릴 수 있습니다.

## 참고 — 지금 기계는 이만큼 걸립니다

비교하실 수 있게 실측값을 적어 둡니다.

| | 실측 |
|---|---|
| ① 받아쓰기 | 음성 길이의 **1.1~1.6배** (CPU) — 10분 통화면 11~16분 |
| ②~⑦ | 건당 **10~18초** |

**받아쓰기가 기계 시간의 90%** 입니다. 그래서 GPU 를 쓰거나 상담 중에 실시간으로
돌리는 것이 다음 과제입니다.

그리고 기계가 끝나도 **사람이 검수하는 시간**이 남습니다. 그건 S5 가 답합니다.
